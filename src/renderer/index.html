시작 프로그램

부팅 시 자동 실행되는 프로그램입니다. 끄면 작업 관리자 > 시작 프로그램의 "사용 안 함"과 같습니다. (삭제하지 않음)

기본 앱 제거

Windows에 기본으로 깔려 있지만 대부분 쓰지 않는 앱입니다. 제거한 앱은 Microsoft Store에서 다시 설치할 수 있습니다. Store·사진·계산기·Xbox 게임 실행 구성 요소 등 필수 앱은 목록에 나오지 않습니다.

Windows 개인화

탐색기·작업 표시줄·테마 설정입니다. 켜고 끌 때마다 원래 값이 백업됩니다.

백업·복원

설정 유지 감시
Windows 업데이트 등으로 적용한 최적화가 원래대로 돌아가면, 프로그램이 켜져 있는 동안 10분마다 확인해 자동으로 다시 적용합니다.

최적화를 적용할 때마다 변경 전 값이 자동 저장됩니다. 항목별 또는 전체를 Windows 원래 값으로 되돌릴 수 있습니다.
