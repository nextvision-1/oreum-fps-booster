안전 주의 위험
🎮 게임 프로필 게임별 고성능 GPU · CPU 우선순위 높음
게임 실행 파일을 추가하면 노트북·내장 그래픽 PC 에서도 그 게임은 항상 게임용 GPU 로 실행되고, CPU 를 먼저 배정받습니다. 제거하면 원래대로 돌아갑니다.

전/후 성능 비교

최적화 전에 한 번, 적용 후에 한 번 측정해서 실제로 얼마나 좋아졌는지 숫자로 비교합니다. 재부팅이 필요한 항목은 재부팅 후 다시 측정하면 더 정확합니다.

시작 프로그램

부팅·로그인 때 자동 실행되는 프로그램(레지스트리·시작 폴더·예약 작업·타사 서비스)입니다. 끄면 자동 실행만 멈추고 프로그램은 삭제하지 않습니다. 서비스는 "수동"으로 바뀌어 필요할 때만 실행됩니다. 보안·드라이버·원격 접속 서비스는 목록에 나오지 않습니다.

기본 앱 제거

Windows에 기본으로 깔려 있지만 대부분 쓰지 않는 앱입니다. 제거한 앱은 Microsoft Store에서 다시 설치할 수 있습니다. Store·사진·계산기·Xbox 게임 실행 구성 요소 등 필수 앱은 목록에 나오지 않습니다.

설정 유지 감시
Windows 업데이트 등으로 적용한 최적화가 원래대로 돌아가면, 프로그램이 켜져 있는 동안 10분마다 확인해 자동으로 다시 적용합니다.
자동 업데이트 확인
프로그램을 켤 때와 6시간마다 새 버전이 있는지 확인해 알려 줍니다. 설치는 직접 눌렀을 때만 진행합니다.

최적화를 적용할 때마다 변경 전 값이 자동 저장됩니다. 항목별 또는 전체를 Windows 원래 값으로 되돌릴 수 있습니다.
